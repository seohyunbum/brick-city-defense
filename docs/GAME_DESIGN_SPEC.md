# 브릭 시티 게임 설계 규격

- 문서 버전: 2.0
- 기준일: 2026-08-21
- 상태: 승인된 목표 규격. `현재`로 표시한 항목만 구현 증거가 있음
- 제품명: 브릭 시티 (오픈월드)

## 0. 2.0 개정 이유 — 요구사항 반전 정정

1.x 는 제품을 "브릭 몬스터 방어전"으로 확정하고, 30행 비목표 목록에 `무한 오픈월드`를 넣었다.
이는 **원 요청(오픈월드형)과 정반대**다. `CLAUDE.md §0`의 docs-first 규칙 때문에 이후 모든 세션이
뒤집힌 전제를 계약으로 상속받았고, 아무도 원 요청과 대조하지 않았다.

2.0 은 이를 되돌린다. 판정 기준은 다음 한 줄이다.

> **이 게임은 자유 이동이 기본이고, 전투는 선택이다.**

웨이브 디펜스 콘텐츠는 삭제하지 않는다. 도시 안에서 **원할 때 참여하는 선택 활동**으로 강등한다(§9).

## 1. 판정 기준

이 문서는 아이디어 목록이 아니라 구현·검수 계약이다. `목표`는 코드, 자동 테스트, 플레이테스트 증거가
모두 연결돼야 `현재`로 승격한다.

| 구분 | 현재 증거 | 목표/차단 기준 |
| --- | --- | --- |
| 실행 | `file://`, GitHub Pages, Windows 바로가기 | 두 경로 회귀 0건 유지 |
| 월드 | (2.0 착수 시점 미구현) | 2048×2048 스터드, 청크 스트리밍, 경계 밖 이동 차단 없음 |
| 이동 | 도보(걷기 22 / 달리기 34) | 탈것 3종, 도보 종주 60초+ / 탈것 25초 내외 |
| 활동 | (2.0 착수 시점 미구현) | 수집·운전·건설·심부름 4종 + 몬스터 이벤트(선택) |
| 진행 | 점수·로컬 최고점수 | 게임오버로 진행이 차단되지 않을 것, 월드 상태 영속 |
| 품질 | 자동 기능 스모크와 렌더 수치 | 드로우콜 650 / 삼각형 125,000 이하를 **월드 어느 지점에서도** 유지 |

## 2. 비전과 설계 기둥

한 문장 비전: "브릭으로 조립된 도시를 아이가 **마음대로 돌아다니며**, 타고, 짓고, 도와주는 오픈월드."

1. **자유가 먼저**: 어떤 시스템도 플레이어를 한 지점에 묶어두지 않는다. 활동은 전부 거절 가능하다.
2. **만져지는 장난감 도시**: 스터드, 플라스틱 광택, 명확한 조립선. 1.x 의 아트 수준은 그대로 계승한다.
3. **길을 잃지 않는 자유**: 넓되 헤매지 않는다. 멀리서 보이는 랜드마크, 나침반, 지도가 항상 방향을 준다.
4. **아이에게 공정한 실패**: 실패해도 잃는 것이 없다. 전투는 선택이며, 피하면 아무 불이익이 없다.

비목표: 공식 완구 제품·세트·캐릭터의 복제, 사실적 총기·폭력, 계정/채팅/광고/결제, 네트워크 멀티플레이,
**강제 전투**, **게임오버에 의한 진행 차단**.

> `무한 오픈월드`는 더 이상 비목표가 아니다. 목표는 **유한하지만 넓은 도시**(§3)다.
> 이 줄을 다시 비목표로 되돌리려면 사용자 승인이 필요하다.

## 3. 월드 규격 (2.0 신규)

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 월드 크기 | 2048 × 2048 스터드 | 도보 34 u/s 로 종주 60초+ — "오픈월드로 느껴지는" 최소 크기 |
| 청크 | 128 × 128, 16 × 16 = 256개 | 드로우콜 예산을 청크 단위로 나누기 위함 |
| 스트리밍 반경 | 근접 3청크(7×7=49) 유지, 그 밖은 해제 | §7 예산 |
| 구역(district) | 12종 내외 | 도심·주택가·공원·항구·공사장·시장·학교·소방서·경찰서·놀이터·농장·차고 |
| 경계 | 물(바다)로 닫는다. 보이지 않는 벽 금지 | 아이가 "막혔다"고 느끼지 않게 |

- 월드는 **시드 기반 절차 생성**이다. `file://` 에서 동적 `import()` 가 막히므로(§CLAUDE.md 1) 청크를
  파일로 스트리밍할 수 없다. 대신 시드에서 런타임에 결정적으로 생성한다.
- 같은 시드는 항상 같은 도시를 만든다. 아이가 "우리 도시"를 다시 찾을 수 있어야 한다.
- 랜드마크(경찰서·크레인·항구 등)는 절차 생성이 아니라 **고정 좌표 프리팹**이다. 방향 기준점이기 때문이다.

## 4. 코어 루프

`탐험 → 발견 → 활동 선택 → 보상 → 도시에 흔적이 남음 → 다시 탐험`

- 루프에 **강제 단계가 없다.** 발견한 활동을 전부 무시하고 계속 돌아다녀도 게임이 성립한다.
- "도시에 흔적이 남음"이 핵심이다. 지은 건물, 모은 브릭, 도운 시민은 저장되고 다음에 와도 그대로다.

## 5. 3C: 캐릭터·카메라·컨트롤

- 도보 기준값은 1.x 를 계승한다: FOV 70(세로 82), 걷기 22, 달리기 34, 눈높이 4.6.
- 숫자 변경은 `src/loadout.js` 에서만 한다.
- 탈것 탑승 시 카메라는 3인칭으로 전환한다(속도감·주변 시야 확보).

## 6. 활동 규격 (2.0 신규)

### 6.1 자유 탐험·수집
- 도시 곳곳에 **황금 브릭**이 숨어 있다. 지붕 위, 골목, 다리 밑 등.
- 수집은 카운터로만 표시하고 실패 개념이 없다. 모은 브릭은 §6.3 건설의 재료가 된다.

### 6.2 탈것 운전
- 자전거 · 자동차 · 헬리콥터 3종. 거리에 배치돼 있고 다가가서 타면 된다.
- 내리면 그 자리에 남는다. 아이가 자기 차를 특정 장소에 세워둘 수 있어야 한다.
- 충돌은 튕겨나옴으로 처리한다. 파괴·수리·연료 없음.

### 6.3 건설·꾸미기
- 모은 브릭으로 정해진 부지에 조립물을 세운다. 팔레트는 `src/bricks.js COLORS` 만 사용한다(하드룰).
- 철거 가능. 되돌릴 수 없는 선택을 만들지 않는다.

### 6.4 NPC 심부름
- 시민 미니피그가 간단한 부탁을 한다(배달·찾기·태워주기). 거절해도 불이익 없음.
- 대화는 2~3줄, 읽기 쉬운 짧은 문장. 읽지 않아도 아이콘으로 목적지를 알 수 있어야 한다.

### 6.5 몬스터 이벤트 (선택 · 구 디펜스)
- §9 참조.

## 7. 성능 계약 (2.0 에서 강화)

하드룰은 `CLAUDE.md §3` 과 동일하다: **드로우콜 650 / 삼각형 125,000 이하**. 목표 550 / 110,000.
2.0 이 추가하는 조건은 **"월드의 어느 지점에서 측정해도"** 다.

1.x 는 54×148 복도 **하나**로 드로우콜 467~499 / 삼각형 97,062~98,114 를 썼다(`docs/AUDIT_2026-08-19.md`).
예산의 76% 를 한 블록에 쓴 셈이고, 그 원인은 `city.js` 가 개별 `.add()` 114회로 도시를 짓고
인스턴싱을 거의 쓰지 않았기 때문이다. 면적이 수십 배인 오픈월드는 이 토대 위에서 성립하지 않는다.

따라서 2.0 은 렌더 구조를 계약으로 못박는다.

- **청크당 드로우콜 상한 8.** 49청크 유지 시 정적 지오메트리 392 + 동적/UI 여유 258.
- 청크 안의 정적 메시는 **재질 계열별로 병합**해 청크당 소수의 메시로 만든다.
  `THREE.BufferGeometryUtils` 는 vendor UMD 번들에 **없다**(deprecation 문자열만 존재).
  따라서 병합기는 `src/geo-merge.js` 로 직접 구현하고, 정점 색(vertexColors)으로 팔레트를 표현한다.
- 반복 장식(가로등·나무·소화전·울타리)은 **월드 단위 InstancedMesh 풀**로 그린다.
- 정적 오브젝트는 `matrixAutoUpdate = false`.
- 거리별 LOD: 근거리 청크만 스터드·창틀 등 디테일을 만든다.

측정 없이 "괜찮다"고 쓰지 않는다. 수치는 `npm run smoke` 의 렌더 패스 계측으로만 승격한다.

## 8. 저장 (2.0 신규)

`src/storage.js` 는 최고점수가 아니라 **월드**를 저장한다.

- 저장 대상: 시드, 플레이어 위치, 수집한 브릭, 지은 조립물, 완료한 심부름, 탈것 위치.
- 절차 생성 지형 자체는 저장하지 않는다(시드에서 재생성). 저장 용량을 작게 유지한다.
- `localStorage` 차단 환경에서는 메모리 fallback 으로 동작하고 경고만 표시한다(1.x 동작 계승).

## 9. 몬스터 이벤트 — 구 디펜스 강등 규격

1.x 의 방어전 자산은 **버리지 않고 도시 안 선택 활동으로 이동**한다.

| 1.x | 2.0 |
| --- | --- |
| 웨이브 10 클리어 = 승리 | 승리 조건 없음. 이벤트는 반복 발생 |
| 하트 0 / 도시 무결도 0 = 게임오버 | **게임오버 없음.** 쓰러지면 근처에서 다시 시작 |
| `support` 상태(웨이브 사이 강제 선택) | 제거. 강화는 도시 안 상점·수집으로 |
| 상시 전투 | 도시 일부 구역에 **가끔** 몬스터 출몰. 접근해야 시작 |
| `objectives.js` 도시 무결도 | 이벤트 1회분의 국소 목표로 축소 |

- 적 4종 모델·AI(`enemies.js`)는 그대로 살린다. 스폰 방식만 웨이브 → **배회/영역 스폰**으로 바꾼다.
- 아이가 전투를 싫어하면 그 구역에 가지 않으면 된다. 그것으로 게임이 끝나지 않아야 한다.
- 아동안전 하드룰(`CLAUDE.md §5`)은 전부 그대로 적용된다: 무생물 상대, 유혈 금지, 시민 공격 불가.

## 10. 아동 안전·접근성

`CLAUDE.md §5` 와 `docs/UX_ACCESSIBILITY_CHILD_SAFETY.md` 를 그대로 계승한다.
2.0 이 추가로 지키는 것:

- **길 잃음 방지**: 나침반 상시 표시, `M` 키 지도, 랜드마크는 멀리서도 보이게.
- **되돌릴 수 없는 선택 금지**: 건설은 철거 가능, 심부름은 거절 가능, 이벤트는 이탈 가능.
- 넓은 월드에서도 reduced-motion 옵션과 카메라 흔들림 상한을 유지한다.
