# UX·접근성·아동안전 규격

- 버전: 1.0
- 기준일: 2026-08-19
- 상태: 목표 규격. 현재 설정 화면과 단계 튜토리얼은 미구현

## 1. 현재 판정

유혈 금지, 사람·동물 적 금지, 시민 공격 금지, 브릭 파편 연출은 좋은 기초 통제다. 그러나 시작 화면이 도구 6개와 키를 한 번에 작은 글씨로 제시하고, 감도/FOV/키/음량/모션 설정, 자막, focus-visible, UI scale이 없다. 따라서 아동안전 표현은 부분 합격, 접근성과 첫 사용 경험은 불합격이다.

## 2. 첫 60초 흐름

0~10초: 한 문장 목표와 `게임 시작`만 강조. 10~25초: 안전 구역에서 WASD와 시선 이동을 행동으로 학습. 25~40초: 검 한 번, 총 한 번을 실제 표적에 사용. 40~60초: 시민 한 명이 위험 방향을 알려 주고 첫 슬라임 2~3체를 막는다.

- 설명을 읽어야만 진행되는 wall of text 금지
- 이미 성공한 조작은 다시 요구하지 않음
- 15초 정체 시 그림+키+짧은 문장 hint
- 첫 웨이브 동안 보스·폭탄·3개 스킬을 동시에 가르치지 않음
- 튜토리얼 재실행/건너뛰기 제공

수락 기준: 첫 사용자 10명 중 8명이 성인 도움 없이 3분 안에 웨이브 1 완료, 첫 의미 공격 30초 이내.

## 3. HUD 정보 위계

1순위는 조준·피격·하트·도시 무결도·즉시 위험, 2순위는 탄약·마나·재사용시간, 3순위는 점수·웨이브·combo다.

- 1080p 중요 텍스트 16px 이상, 보조 텍스트 14px 이상
- UI scale 80/100/125/150%
- 대비 4.5:1 이상을 목표로 자동/수동 확인
- 색만으로 상태를 전달하는 cue 0건. icon/shape/text/sound 중 하나를 추가
- crosshair와 threat indicator가 DoF·VFX로 사라지지 않음
- 화면 모서리 HUD는 safe area와 24px 이상 여백

## 4. 설정 최소 세트

| 영역 | 필수 설정 | 저장 |
| --- | --- | --- |
| 화면 | 품질 low/high, UI scale, fullscreen 도움 | local |
| 카메라 | 감도 0.5~2.0, FOV 60~100, 수직 반전 | local |
| 모션 | head-bob, screen shake, DoF, reduced-motion | local |
| 입력 | 키 remap, 기본값 복원, 마우스 버튼 안내 | local |
| 오디오 | master/music/sfx/ambience, mute | local |
| 접근성 | 고대비, 색각 보조 pattern, 자막/시각 음향 cue | local |
| 난이도 | 쉬움/기본. 적 피해·예고·자원 차이를 명시 | 세션/로컬 |

저장소 차단·quota·손상값에서는 default로 복구하고 게임 부팅을 막지 않는다.

## 5. 키보드·포인터 락

- Tab/Enter/Space/Escape만으로 시작, 설정, 일시정지, 재개, 결과, 재시작을 완료
- 모든 버튼에 보이는 `:focus-visible` outline
- 포인터 락 거부 시 반복 오류 대신 클릭/키보드 재시도 안내
- Alt+Tab/blur 때 자동 pause, 입력 stuck 해제
- 키 remap 충돌을 저장 전에 알림
- 화면 회전/좁은 화면에서 필수 버튼이 겹치지 않음

ARIA name, heading 순서, live region은 HUD 업데이트 빈도를 제한해 screen reader를 폭주시키지 않는다.

## 6. 모션·감광·멀미

- 반복 플래시 3Hz 이상 금지, 전체 화면 고대비 flash 금지
- 피격 flash 불투명도/시간 상한과 reduced-motion 대체 표시
- head-bob·shake off 가능, reduced-motion은 기본 효과의 20% 이하
- DoF off 제공. 적과 crosshair는 어떤 설정에서도 선명
- FOV 60~100, 갑작스런 FOV kick 금지
- 강제 카메라 회전·긴 조작 불능 연출 금지

## 7. 아동안전·개인정보

기본 정책은 다음 모두 0이다: 계정, 로그인, 채팅, UGC, 친구 목록, 광고, 인앱결제, 외부 상점, tracker, analytics, 위치, 카메라/마이크, 개인정보 입력, 쿠키 banner가 필요한 추적.

런타임 네트워크는 own-origin 정적 파일만 허용한다. 외부 링크를 추가하려면 게임 밖 보호자 gate와 목적·도메인 검토가 필요하다. URL 공유는 각자 같은 정적 게임을 여는 것이며 멀티플레이/채팅이 아니다.

적은 무생물 브릭 몬스터로 제한하고 피·상처·절단·현실적 비명·현실 총기 표현을 쓰지 않는다. 시민은 피해 대상이 아니라 구조 상태로 표현하며 공격 입력이 시민에게 무효임을 테스트한다.

## 8. 브랜드·팬 프로젝트 고지

공개 제품명·URL·아이콘은 독립 `브릭 시티`를 사용한다. 공식 로고·패키지·세트명·게임 이미지 사용 금지. 필요한 상표 언급은 서술적이고 강조하지 않으며 비후원·비승인 고지를 함께 둔다. 고지는 잘못된 상표 사용을 자동 치유하지 않으므로 이름과 자산 자체를 먼저 독립화한다.

## 9. 실패 메시지

아이에게 행동 가능한 한 문장으로 쓴다. 기술 stack, 경로, 예외 text를 그대로 노출하지 않는다. 개발자 세부 오류는 console에, 화면에는 `게임을 다시 열어 주세요`, `소리를 켜려면 시작 버튼을 눌러 주세요`처럼 표현한다. 오류 text는 `textContent`로 넣는다.

## 10. 수락 매트릭스

- 키보드만: 전체 시작→플레이→pause→결과→재시작 PASS
- 저장 차단: 부팅·점수·설정 fallback PASS
- 720p/1080p/1440p/4K, DPR1/2에서 overlap 0
- 중요 text 16px, 보조 14px, 대비 4.5:1, color-only cue 0
- reduced-motion/DoF off/head-bob off 동작
- screen reader 버튼 name과 focus 순서 PASS
- first-user 8/10 웨이브1 완료
- own-origin 외 요청·계정·채팅·광고·결제·tracker·PII 0

이 매트릭스 증거가 없으면 접근성/아동안전 완료라고 보고하지 않는다.
