# 단편 「여든여섯 번째 새벽」 — 미래의 브릭 시티

- 버전: 1.0
- 기준일: 2026-09-06
- 상태: 6컷 · 74초 재생, 자동 스모크(`npm run smoke:story`) 통과. 하드웨어 프레임 인증은 미실시.

## 1. 무엇인가

`story.html` 을 더블클릭하면 도는 **약 74초짜리 3D 단편**이다. 게임 본편과 같은 브릭 부품·팔레트·
three.js 런타임을 쓰지만, 룩과 카메라는 셀 애니메이션 문법(툰 밴딩 · 잉크 외곽선 · 역광 림라이트 ·
2.39:1 레터박스 · 자막)을 따른다.

이야기는 미래의 브릭 시티(2186년)다. 벽 바깥에서 낡은 무인 기계 무리가 다가오고, 네 다리로 걷는
작업기 **86호기**가 아침을 지키러 나갔다가 해가 뜬 광장으로 돌아온다.

애니메이션 연출 톤을 참고한 **오리지널 단편**이다. 특정 애니메이션·완구사의 캐릭터·기체·세트명·
로고·대사·자산을 쓰지 않으며, 모든 형상은 이 저장소의 코드가 런타임에 생성한다(외부 자산 0개).

## 2. 컷 구성

| # | 컷 | 길이 | 무엇을 보여 주는가 |
| --- | --- | --- | --- |
| 1 | `dawn` | 10초 | 성벽 안쪽 스카이라인. 카메라가 천천히 올라가며 도시를 연다 |
| 2 | `horizon` | 10초 | 성벽 위에서 본 지평선. 먼지 기둥과 기계 실루엣 |
| 3 | `hangar` | 12초 | 격납고 등이 켜지고, 시민 파일럿이 달려와 사다리를 올라 조종석에 탄다 |
| 4 | `march` | 14초 | 낮은 앵글 트래킹. 86호기가 트롯 보행으로 도시를 가로지른다 |
| 5 | `clash` | 13초 | 벌판에서 스터드 발사기 4발. 맞은 기계는 브릭이 되어 흩어진다 |
| 6 | `sunrise` | 15초 | 해가 뜨고 시민이 광장으로 돌아온다. 86호기는 무릎을 접는다. 타이틀 카드 |

자막은 컷마다 2~3번 바뀐다. 대본·타이밍의 정본은 `src/story86.js` 의 `SHOTS` 하나다.

## 3. "자연스러운 움직임"을 만든 방법

`src/motion.js` 가 도구, `src/mech86.js`·`src/story86.js` 가 사용처다.

- **가감속** — 모든 컷 전환·카메라 이동·무릎 접기는 이징 곡선을 지난다(`Ease.inOutCubic`,
  착지감이 필요한 곳은 `outBack`/`outBounce`).
- **관성과 잔진동** — 카메라 위치·주시점, 몸통 상하·좌우, 포탑 회전, 포신 반동은 전부 2차 스프링
  (`Spring`, `Spring3`)이다. 목표가 갑자기 바뀌어도 속도가 이어지므로 살짝 지나갔다 돌아온다.
- **발이 미끄러지지 않는 보행** — 발 미끄러짐 0 의 조건은 `cadence = speed × duty / stride` 다.
  이 관계를 `mech86.js` 가 지키고, 발 목표는 접지/유각 위상(`footCycle`)으로 만든 뒤
  2관절 IK(`ik2`)로 무릎 각을 푼다. 접지한 발은 세계 좌표에서 제자리에 박힌다
  (스모크 실측: 몸이 한 프레임에 움직인 거리의 **6.4%**).
- **무게** — 대각선 두 다리가 새로 닿을 때마다 몸통이 살짝 주저앉고, 가속하면 앞으로 기운다.
- **2차 운동** — 안테나 세 마디는 몸통의 각속도를 늦게 따라오는 채찍 운동이다.
- **생명감** — 서 있는 미니피그도 완전히 멈추지 않는다(숨 · 고갯짓). 카메라에는 결정적 값 노이즈
  (`Noise1D.fbm`)로 아주 약한 손떨림이 들어간다.

## 4. 룩

`src/cel.js` 가 셀 룩 계약을 들고 있다.

- **툰 밴딩** — 4단 그라데이션 맵 + `MeshToonMaterial`. 게임 본편의 PBR 부품은 `Cel.celify()` 로
  텍스처를 유지한 채 다시 칠한다.
- **잉크 외곽선** — 뒤집힌 껍데기(inverted hull). 드로우콜이 두 배가 되므로 주인공(86호기 · 파일럿 ·
  기계)에만 붙인다.
- **하늘** — 카메라를 따라다니는 돔 + 지평선 바로 위의 따뜻한 띠. 안개 색을 지평선 하늘색과 같게
  맞춰 땅 끝 경계선을 없앴다.
- **색** — `src/bricks.js` 의 `COLORS` 팔레트만 쓴다. 시네마틱 전용 색(`cine*`)도 팔레트에 등록했다.

## 5. 아동안전·브랜드

- 상대는 사람도 동물도 아닌 **무인 3각 기계**다. 유혈 없음. 쓰러지면 브릭이 팝 하고 흩어진다.
- 시민 미니피그는 지켜야 하는 대상이고, 조종석에 타는 파일럿도 시민이다.
- 반복 점멸·감광 효과 없음. 총구 섬광은 발사마다 0.07초 한 번뿐이다.
- 카메라 흔들림은 아주 약하고, `prefers-reduced-motion` 을 자동으로 따르며 화면의
  **🐢 모션 줄이기** 버튼으로 언제든 끌 수 있다(흔들림 0 · 입자 수 감소).
- 자막은 끌 수 있다. `Space`/`R`/`←→` 키와 컷 점프 칩으로 언제든 멈추고 되돌릴 수 있다.
- 광고·과금·계정·수집·UGC 없음. 페이지 밖으로 나가는 링크도 없다
  (게임 시작 화면의 링크는 같은 폴더의 `story.html` 로 가는 내부 이동이다).

## 6. 성능

셀 룩은 후처리를 쓰지 않고 그림자는 한 프레임 걸러 갱신한다. 스카이라인 30동과 브릭 파편은
`InstancedMesh` 한 번으로 그린다. 파편·먼지는 풀링이며 프레임마다 새 객체를 만들지 않는다.

- 자동 스모크 실측 최대: **드로우콜 336 / 650, 삼각형 46,792 / 125,000** (1400×900, 여섯 컷 중 최댓값)
- 소프트웨어 렌더러 FPS는 하드웨어 증거가 아니다(`QA_PERFORMANCE_RELEASE_GATES.md` §3).

## 7. 검증

```powershell
npm ci
npm run verify:static      # story.html 의 CDN 금지·모듈 순서·모듈 크기 래칫 포함
npm run smoke:story        # file:// 부팅, 콘솔 오류 0, 여섯 컷·자막, 예산, 발 미끄러짐, 토글, 타이틀 카드
```

증거 스크린샷은 `.smoke-story/` 에 남는다. 남은 수동 게이트: 실제 하드웨어에서의 p95 frame-time,
그리고 아이와 함께 보는 관찰 테스트(자막 속도·이해도).
